 Student Career Roadmap

A Python-based desktop application that helps students choose a career path, identify required skills, track completed and missing skills, and monitor their career preparation progress.

Features

* Select a career path
* Enter existing skills
* Generate a personalized career roadmap
* Display completed and missing skills
* Calculate skill completion percentage
* Track progress using a progress bar
* Save student details using SQLite
* View saved student data
* Reset and exit options

Technologies Used

* Python
* Tkinter
* SQLite
* SQLite3

Career Paths

* **Python Developer:** Python, SQL, DSA, Django, Git & GitHub
* **Web Developer:** HTML, CSS, JavaScript, React, Git & GitHub
* **Data Analyst:** Python, SQL, Excel, Pandas, Power BI
